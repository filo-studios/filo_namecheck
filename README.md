# filo_namecheck

A small FiveM connection gate that checks players as they connect:

- **Cfx.re account check:** requires players to be signed in to a Cfx.re account (i.e. they have a `fivem:` identifier).
- **Auto-name check:** catches FiveM's auto-generated player names such as `SlowBat8645` or `BreezyDuck8244`, and either blocks the player or warns them.

Each check can be turned on or off on its own.

## Installation

1. Put the `filo_namecheck` folder in your `resources` directory.
2. Add it to your `server.cfg`:
   ```cfg
   ensure filo_namecheck
   ```

## Configuration

The settings are at the top of `server.lua`:

```lua
local CHECK_CFX  = true   -- require a linked Cfx.re account
local CHECK_NAME = true   -- check for FiveM auto-generated names
local BLOCK      = true   -- name check only: true = block, false = warning card
```

| Option | Description |
|---|---|
| `CHECK_CFX` | Refuses players who don't have a Cfx.re account linked. |
| `CHECK_NAME` | Checks the player name against FiveM's default name pattern. |
| `BLOCK` | Only applies when `CHECK_NAME` is on. `true` refuses the connection with a message. `false` shows a card asking the player to change their name, with an **I Understand, Continue** button that lets them join anyway. |

### Common setups

| Setup | `CHECK_CFX` | `CHECK_NAME` | `BLOCK` |
|---|---|---|---|
| Strict (account + real name required) | `true` | `true` | `true` |
| Account required, name warning only | `true` | `true` | `false` |
| Account only | `true` | `false` | – |
| Name only | `false` | `true` | `true` / `false` |

Run `ensure filo_namecheck` after changing any setting.

## How auto-names are detected

FiveM's default names follow the pattern `<Adjective><Animal><4 digits>`. The resource matches:

```
^%u%l+%u%l+%d%d%d%d$
```

That is: a capitalized word, a second capitalized word, then exactly four digits. A real name that happens to follow the same pattern (for example `JohnSmith1234`) will also match.

## What players see

- **No Cfx.re account:** *You must link a Cfx.re account to join. In FiveM, open Settings > Account, sign in to Cfx.re, then reconnect.*
- **Auto-name, `BLOCK = true`:** *Your name "X" is auto-generated by FiveM. Change it in FiveM Settings and reconnect.*
- **Auto-name, `BLOCK = false`:** a card with steps for changing the name and a Continue button. If the player doesn't respond, they're let in after 2 minutes so the connection never hangs.
